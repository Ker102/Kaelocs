# Getting Support

Need help using Kaelocs?

- 📚 Start with the [README](./README.md) and docs in `/docs`.
- 🐞 Found a bug? Please open an issue using the bug report template.
- 💡 Have an idea? Use the feature request template so we can discuss it.
- 🔐 Security concerns? Email security@kaelocs.com.

For anything else, reach out to support@kaelocs.com and we'll point you in the right direction.
