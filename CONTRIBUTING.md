# Contributing to Kaelocs

🎉 Thanks for your interest in contributing! This guide walks you through our process so you can get productive quickly.

## Code of Conduct
Please read and follow the [Code of Conduct](./CODE_OF_CONDUCT.md). We take it seriously.

## Ways to contribute
- Report bugs using the [bug template](.github/ISSUE_TEMPLATE/bug_report.yml)
- Request new features via the [feature request template](.github/ISSUE_TEMPLATE/feature_request.yml)
- Improve docs, tests, or developer tooling
- Submit fixes or enhancements for the Next.js app, API routes, or AI integrations

## Development workflow
1. Fork the repo and create a branch from `main`.
2. Install dependencies with `npm install`.
3. Start the dev server using `npm run dev`.
4. Make your changes and add tests whenever possible.
5. Run `npm run lint` and `npm test` before opening a PR.
6. Fill out the [pull request template](.github/PULL_REQUEST_TEMPLATE.md).

## Commit style
We prefer concise, descriptive commit messages, e.g. `feat: add admin audit logging`.

## Pull request checklist
- [ ] Tests cover the new behavior or regression
- [ ] Documentation updated (README, docs/, or inline comments)
- [ ] CI is green (lint, tests, and CodeQL)
- [ ] Changes keep the app accessible and responsive

## Getting help
Need assistance? Open a discussion or reach out via support@kaelocs.com.
